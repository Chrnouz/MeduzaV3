## Installation

### Ubuntu / Debian / Kali Linux / NetHunter

**1. Install Git**

```bash
sudo apt update
sudo apt install -y git
```

**2. Clone the repository**

```bash
git clone https://github.com/Chrnouz/MeduzaV3.git
```

**3. Open the project directory**

```bash
cd MeduzaV3
```

**4. Make the installation script executable**

```bash
chmod +x install.sh
```

**5. Start the installation**

```bash
./install.sh
```

The installation script automatically handles Python, pip, virtual environment setup, and dependencies listed in `requirements.txt`.

### Termux

```bash
pkg update && pkg upgrade -y
pkg install git -y
git clone https://github.com/Chrnouz/MeduzaV3.git
cd MeduzaV3
chmod +x install.sh
./install.sh
```

### macOS

Install Git using Homebrew:

```bash
brew install git
```

Then clone and install:

```bash
git clone https://github.com/Chrnouz/MeduzaV3.git
cd MeduzaV3
chmod +x install.sh
./install.sh
```
